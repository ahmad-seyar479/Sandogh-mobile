# سیستم مدیریت صندوق اتحادیه — نسخه موبایل (اندروید)

این نسخه بازنویسی‌شده‌ی اپلیکیشن دسکتاپ (PySide6) شماست، با کتابخانه‌ی **Kivy** برای
اجرا روی اندروید. منطق دیتابیس (`db.py`) عیناً از نسخه‌ی دسکتاپ گرفته شده — همان
جدول‌ها، همان قوانین محاسبه‌ی موجودی صندوق، همان تاریخ شمسی/دری.

## چه چیزی منتقل شده؟

- ورود با نام کاربری/رمز عبور (پیش‌فرض admin/admin — دقیقاً مثل نسخه دسکتاپ)
- مدیریت اعضا: افزودن، ویرایش، حذف، جستجو
- جدول ماهانه‌ی حق عضویت (با احتساب تاریخ عضویت، مثل نسخه دسکتاپ)
- قرض‌ها: ثبت قرض، ثبت اقساط بازپرداخت، مشاهده‌ی باقی‌مانده
- کمک‌های دریافتی و اهدائی
- موجودی صندوق + گزارش تراکنش‌ها + خروجی CSV (قابل بازکردن در Excel)
- تغییر رمز عبور و مبلغ حق عضویت ماهانه
- بکاپ‌گیری از فایل دیتابیس

## چه چیزی هنوز کامل نیست (قدم‌های بعدی پیشنهادی)

- **خروجی Excel/PDF با فرمت‌بندی کامل** مثل نسخه دسکتاپ (فعلاً فقط CSV ساده پیاده شده،
  چون کتابخانه‌های openpyxl/reportlab روی اندروید بسته‌بندی پیچیده‌تری نیاز دارند)
- **بازیابی از فایل بکاپ از داخل خود اپ** (فعلاً باید فایل را با یک برنامه مدیریت فایل
  جایگزین کنید — توضیح در تب «بکاپ و بازیابی»)
- چیدمان کامل راست‌به‌چپ (متن‌ها راست‌چین هستند، اما چیدمان کلی صفحات مثل دسکتاپ کاملاً
  آینه نشده)
- تست واقعی روی گوشی — من این کد را نوشته‌ام اما امکان اجرای واقعی Kivy/Android در محیط
  من نبود؛ حتماً قبل از استفاده‌ی جدی، آن را تست کنید.

## قدم ۱: فونت فارسی (ضروری)

به `fonts/README.md` مراجعه کنید و فایل فونت را اضافه کنید. بدون این فایل، حروف فارسی
درست نمایش داده نمی‌شوند.

## قدم ۲: ساخت فایل APK

### روش پیشنهادی: GitHub Actions (خودکار، بدون نیاز به نصب چیزی روی کامپیوتر شما)

۱. یک مخزن (Repository) در [github.com](https://github.com) بسازید و تمام فایل‌های این
   پوشه (از جمله پوشه‌ی مخفی `.github` و پوشه‌ی `fonts` با فونت اضافه‌شده) را در آن
   آپلود کنید.
۲. به تب **Actions** بروید، روی workflow با نام «Build Android APK» کلیک کنید، سپس
   **Run workflow** را بزنید.
۳. ساخت اپلیکیشن اندروید معمولاً ۱۵ تا ۳۰ دقیقه طول می‌کشد (بار اول کندتر است چون
   ابزارهای اندروید دانلود می‌شوند).
۴. بعد از پایان (تیک سبز)، وارد همان اجرا شوید و فایل **SandoghApp-android** را دانلود
   کنید — یک فایل zip شامل `.apk` است.
۵. فایل `.apk` را به گوشی اندرویدی منتقل کنید و نصب کنید (باید گزینه‌ی «نصب از منابع
   ناشناس» را در گوشی فعال کنید، چون از گوگل‌پلی نصب نمی‌شود).

### روش دوم: ساخت روی سیستم لینوکسی خودتان (چون شما با Android Studio راحت هستید)

اگر ترجیح می‌دهید خودتان بسازید (روی لینوکس یا WSL — Buildozer روی ویندوز مستقیم کار
نمی‌کند):

```
pip install buildozer cython==0.29.36
buildozer android debug
```

فایل `.apk` نهایی در پوشه‌ی `bin/` قرار می‌گیرد. اولین بار که این دستور را اجرا کنید،
Buildozer به‌صورت خودکار Android SDK/NDK را دانلود می‌کند (چند گیگابایت، نیاز به
اینترنت خوب دارد).

## ساختار پروژه

```
main.py                 نقطه ورود، ثبت فونت، مدیریت صفحات
db.py                    لایه دیتابیس (همان منطق نسخه دسکتاپ)
style.kv                 رنگ‌ها و استایل مشترک ویجت‌ها
utils/farsi_text.py       شکل‌دهی صحیح حروف فارسی/دری برای Kivy
utils/jalali.py           کمک‌توابع تاریخ شمسی
screens/                  هر صفحه یک فایل (ورود، داشبورد، اعضا، حق عضویت، قرض، کمک، ...)
buildozer.spec            تنظیمات ساخت اندروید
.github/workflows/        ساخت خودکار APK با GitHub Actions
```

## تست روی کامپیوتر خودتان قبل از ساخت APK (پیشنهادی)

قبل از ساخت APK (که وقت‌گیر است)، بهتر است اول روی خود کامپیوتر با پایتون تست کنید:

```
pip install kivy jdatetime arabic-reshaper python-bidi
python main.py
```

اگر روی دسکتاپ درست کار کرد (با همان فونت)، احتمال مشکل روی اندروید هم کم می‌شود.

## سوالات متداول

**آیا داده‌های فایل `sandogh.db` فعلی من منتقل می‌شود؟**
نه — طبق درخواست شما، فقط ساختار جدول‌ها حفظ شده و اپ با یک دیتابیس خالی (با کاربر
admin/admin پیش‌فرض) شروع می‌کند.

**آیا می‌توانم بعداً iOS هم اضافه کنم؟**
بله، Kivy از iOS هم پشتیبانی می‌کند اما ساخت آن حتماً باید روی مک انجام شود (چیزی که
GitHub Actions هم می‌تواند با runner مک انجام دهد، اما پیچیده‌تر و کندتر است).
